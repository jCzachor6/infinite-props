Verified locally on macOS arm64, 2026-10-13. Stage 7 adds contextual
`density { key: height, ... }` distribution literals, shared immutable point
snapshots, clipped piecewise linear integration and a stable binary64 inverse.
It reuses the stage-6 point pool/builders. Product/source/format remain
0.7.0 / 0.7 / 0.6, C API 0.3, ABI 0.4, language schema 3 and diagnostics 1.
Surface stages and the full 0.7 release remain later work.

## Independent numerical and historical evidence

Before edits, unmodified stage-6 tools from `3120751` were preserved in
`/private/tmp/iprop-v07-stage7-baseline-tools`. Their compiler SHA256 is
`9bba83eb71a075d0371f610dc5a2dcf3be917dc639f5731db10e2ccfa24feec6`.
They produced the actual weighted binaries and five-seed results in
[`frozen-format-v0.6-stage6.json`](../tests/fixtures/frozen-format-v0.6-stage6.json).
These bytes are executed directly; earlier pins were never regenerated by the
changed compiler. Earlier source identity is
`/private/tmp/iprop-v07-stage7-source-identity.json`.

[`density-v0.6-vectors.json`](../tests/fixtures/density-v0.6-vectors.json) contains
15 numerical cases / 195 independently generated vectors. Its raw edge seeds
invert splitmix32 to hit hashes 0/1, quarter/half/three-quarter boundaries and
0xfffffffe/0xffffffff. Expected bits come from the separate Python binary64
model in [capture_density_vectors.py](../scripts/capture_density_vectors.py),
not the native or WASM runtime. Independent 90-digit Decimal integration checks
the conditional CDF, accounting for coordinate-origin/span conditioning.
Operation-order and ideal-real f32 bits are recorded separately: the contract
pins binary64 operations and final conversion, not correct rounding of an
ideal real-arithmetic inverse at every extreme coordinate. The sampled maximum
CDF discrepancy is 8.149072527885437e-10 for large-offset/narrow-span keys.

The existing source literal grammar reports strtof underflow for a literal
smallest subnormal. The vector sources therefore construct it through exact
binary32 multiplication of minimum normal by 2^-23, preserving that older
acceptance boundary while exercising nonzero tiny density areas.
