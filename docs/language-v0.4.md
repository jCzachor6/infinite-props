# The frozen v0.4 source language

The released 0.4 reference is preserved in the
[frozen benchmark handbook](../benchmarks/llm/baseline-reference/handbook.md)
and the original v0.4.0 SDK under `docs/language-v0.4.md`.
Those bytes are historical inputs and are not regenerated by current tools.

The current [v0.5 source-language reference](language-v0.5.md) uses the shared
[handbook chapters](language/index.md). Current tools generate
`build/language-docs/docs/language-v0.5.md`, even while the product and binary
format retain their independent 0.4 versions.
