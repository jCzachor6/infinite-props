What is Infinite Props?

Infinite Props is a portable binary format and an open-source toolchain for seed-based procedural 2D assets. You describe a prop once in the small .ips language, compile it to a self-contained .iprop file, and a tiny sandboxed virtual machine turns any seed into pixels, bit for bit the same in the browser, in your engine and on every operating system.

One file is not one image. It is a recipe for endless variations, and every result comes with the data your game needs: colliders, anchor points and colours.

Main features

Bit-exact determinism

The same seed renders the same pixels and outputs on every platform and backend. A committed golden corpus guards every release.

One file, endless props

An .iprop file is a recipe, not an image. Seed, variant and archetype unlock a practically unlimited, reproducible family of sprites.

Safe to run anywhere

Validated bytecode, structured control flow only and a hard fuel budget: even an untrusted file cannot hang or escape its host.

A language for pixels

.ips speaks sprites: palettes, rects, distance helpers, lo to hi ranges and colour gradients, compiled with precise diagnostics.

Shaped randomness

Gaussian, triangular and beta distributions steer every roll, so proportions look designed rather than noisy.

Composable parts

Import a blade, a hilt, a face. Parts link into one self-contained binary, paint in call order and report outputs in the caller's coordinates.

Structured outputs

Colliders, anchors and colours come back with the pixels: the tip of a sword, the eyes of a portrait, the colour of a hat.

Tiny binaries

Each weapon pack on this page compiles to 7 to 11 KB. Files are zlib-packed whenever that is smaller and never need external resources.

Runs everywhere

One reference interpreter for Linux, macOS, Windows and WebAssembly. The tiles above are running it in this page.

C API and engines

A C99 interface on a versioned ABI (C API {{C_API_VERSION}}, SONAME {{C_ABI_SOVERSION}}), with SFML and Godot GDExtension integrations built on top.

Authoring toolchain

ipc, ipgen, ipsheet, ipdis, ipval and a VS Code extension with live preview, atlas and bytecode inspector.

Ready for coding agents

A compact, machine-checked LLM reference ships with every release, so an agent can write props in .ips alongside you.
