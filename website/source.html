Build from source

You need a C++20 compiler, CMake 3.24 or later and zlib 1.2.9 or later (Linux: zlib1g-dev; macOS: the platform SDK; Windows: vcpkg).

git clone https://github.com/jCzachor6/infinite-props.git
cd infinite-props
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
ctest --test-dir build --output-on-failure

The tools land in build/tools/. The optional SFML and Godot backends are described under Backends.

The WebAssembly module and this website

emcmake cmake -S backends/html5 -B build/wasm -DCMAKE_BUILD_TYPE=Release
cmake --build build/wasm --parallel
sh website/prepare.sh build/wasm build/tools
npm --prefix website ci
npm --prefix website run build
node website/test/release-smoke.js website/dist build/tools

The smoke test checks every link and compares the website's WebAssembly renders with the native tools pixel for pixel.

tests/, benchmarks/unit, golden and conformance tests; runtime and compiler benchmarks

Contributing

  • The specification is the contract. Change spec/ first, then the code.
  • Determinism is sacred. No time, threads or FMA contraction in generation; branches on integers only.
  • Golden tests are the law. A change to a golden image or output is a breaking change.

The full guide is in CONTRIBUTING.md; issues and ideas go to the issue tracker.
