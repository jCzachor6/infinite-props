The .ips language

A small imperative language that lowers to the frozen VM operations. The grammar, the type rules and the compiler live in the repository (language/, compiler/); this page is the reference summary.

The asset block

asset name {
  size WxH          // required — the canvas in asset units
  origin x,y        // the placement anchor
  variants N        // declared variant count (default 1)
  archetypes N      // declared archetype count (default 1)
  input  type name = default
  output [list] kind name

  draw { ... }
  helper(u: f32, c: color) -> i32 { ... }
}
  • draw { ... } is the entry block; the read-only v and a are the variant and archetype indices (validated against the declared counts). The compiler synthesizes the runtime parameters; the old draw(v: i32, a: i32) declaration is rejected. Pass these values to helpers through their typed parameters.
  • Helpers declare their parameter types (u: f32 — i32, f32, color or vec2; pre-1.0 the type is mandatory) and functions that return a value declare an explicit return type (-> i32). Recursion is not supported.

Inputs and outputs

input typemeaning
coloran RGBA colour; default #RGB, #RGBA, #RRGGBB or #RRGGBBAA; short forms repeat each digit
f32a 32-bit float; default a numeric literal
u32an unsigned 32-bit integer; default a non-negative literal

Inputs are uniforms: the host supplies values (defaults apply otherwise); inside draw they read as i32/f32/ color values.

Outputs are structured slots written in draw:

kindwrite shape
point{x, y}
circle{x, y, r}
rect{x, y, w, h}

output list slots append every write in program order.

Statements

w = range(21, 31)      // declares and assigns a local (first use fixes its type)
if (index(3) == 0) { ... } else if (...) { ... } else { ... }
while (i < 10) { ... }   // the condition is evaluated each iteration
for i in 0..10 { ... }   // exclusive upper bound, evaluated once
break                    // leave the innermost loop in this function
continue                 // next iteration; for-loops still increment
return [value]
face(v, a)             // a call as a statement (values are dropped)
  • Locals are typed on first assignment; reassignment must match the type exactly. Storable types are i32, f32, color and vec2.
  • Conditions must be i32 (any non-zero is true).
  • Semicolons are optional separators. Comments: // and /* */.

Constant palettes

palette colors = [#112233, #445566, #778899]
palette widths = [1, 2, 3]
// inside draw or a helper:
c = colors[v]
w = widths[index(3)]

Palettes are non-empty arrays of literals of one scalar type: i32 (including true/false), f32 or color. The index must be an i32; negative or out-of-range indices select the last element. Palettes cannot be assigned to or used without an index.

Expressions and operators

7   -3   2.5   #808d74   true   false   0x9e3779b9
seed                 // the current stream state (i32)
v, a                 // the variant and archetype indices
{e1, e2}             // a storable vec2; also usable as a point
{e1, e2, e3}         // a circle output literal
{e1, e2, e3, e4}     // a rect output literal

Operators, loosest to tightest: || && | ^ & == != < <= > >= << >> + - * / % unary - ! ~.

  • Mixed i32/f32 arithmetic promotes to f32; % and the bitwise/logical operators are i32-only; >> shifts unsigned.
  • Vectors can be stored, passed to helpers, returned and queried through .x/.y. Circle and rectangle compounds flow straight into output writes; they are not storable local types.

Formatting, diagnostics and recipes

ipc asset.ips --format canonical.ips
ipc asset.ips --debug --no-compress

Formatting uses canonical words, two-space indentation and named builtin arguments in signature order. Reformatting is idempotent; executable roundtrips preserve bytes after stripping debug data. Diagnostics use one-based UTF-8 codepoint columns and suggest close canonical names.

The full language reference lists exact parameter names. The 24 recipe sources cover small patterns for geometry, RNG, palettes and outputs. Compiler passes retain pixels/output bits and only accept complete expanded artifacts that do not grow; see optimization behavior.

Emoji aliases

18 exact single Unicode scalars are accepted alongside word spellings. The AST, diagnostics and formatter normalize them to canonical words; strings and comments retain their text. Variation selectors and ZWJ sequences are rejected in syntax. Namespace members retain word spelling.

📦 example {
  size 8x8
  ✏ { 🟦(0, 0, 8, 8, #345) }
}

The alias table pins every codepoint: draw uses U+270F and archetypes uses U+1F5C2 without selectors.

Parts and composition

import hair from "hair.ips"

asset portrait {
  size 64x64
  output point pupilCenter
  draw {
    hair.draw(seed ^ 0x9e3779b9, v, a, at = {32, 4}, color = #33291f)
    pupilCenter = hair.outputs.top
  }
}
  • Parts are separate assets linked at compile time; the compiler merges them into one self-contained binary (imports are acyclic).
  • The call passes (seed, variant, archetype) plus a required at = {x, y} placement and named uniform overrides. Call order is paint order.
  • Optional rot = 0/90/180/270, mirror_x = 0/1 and mirror_y = 0/1 select exact D4 transforms for raster and part-owned outputs, including helper-written outputs and lists.
  • part.outputs.name reads the last called part's structured output; assigning it to your own output propagates it upward.
