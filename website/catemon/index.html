    How one small file makes every catemon

    There is no list of catemons behind this page. Each one is drawn on the spot by a 23 kB program, catemon-1.iprop, running in your browser on the Infinite Props runtime. A name is turned into a number, the number is the program's seed, and the seed decides everything: the kind, the pose, the build, the coat and its blotches, the eyes, the tail and every colour. The same name gives the same catemon on every device, and nothing is uploaded.
